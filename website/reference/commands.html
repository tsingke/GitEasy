Git命令速查

按任务找到命令，结合场景确认前提与影响范围。占位符需要替换，表格中的不同形式不能整行当作脚本执行。

环境与仓库

命令用法场景与边界
git versiongit --version记录校园项目实验的Git版本版本输出不证明权限
git helpgit help merge查询合并选项与适用条件按本机版本查阅
git configgit config --local user.name "Li"为课程仓库设置提交姓名不等于平台登录
git configgit config --show-origin --get user.email诊断生效邮箱及来源只读查询
git initgit init -b main建立校园项目新历史尚未产生根提交
git clonegit clone SOURCE campus-copy取得可访问来源并建立本地仓库SOURCE需替换
git rev-parsegit rev-parse --show-toplevel确认当前所在仓库根目录不按文件夹名猜测

工作区、索引与提交

命令用法场景与边界
git statusgit status --short提交前区分两列变化注意忽略范围
git diffgit diff -- src/检查核心代码未暂存变化索引对工作区
git diffgit diff --cached审阅拟提交的业务修复HEAD对索引
git diffgit diff HEAD查看工作文件相对当前提交不是只看候选
git addgit add src/card_service.cpp选取当前核心文件内容以后编辑不自动纳入
git addgit add -p将独立修改分别选择核对依赖与上下文
git commitgit commit -m "fix: reject lost-card payment"记录一次业务意图普通提交使用索引
git commitgit commit --amend整理尚未共享的最近说明或候选建立替代身份
git commitgit commit --fixup HEAD标记对最近提交的补充后续可autosquash
git rmgit rm --cached -- demo.csv停止在新快照中跟踪演示导出旧历史仍可能保留
git mvgit mv old.md new.md重命名文档并选择候选变化重命名检测另行理解

文本规则与查找

命令用法场景与边界
git check-ignoregit check-ignore -v build/cache.txt查明构建缓存命中哪条忽略规则已跟踪路径另查
git check-attrgit check-attr text eol -- src/main.cpp核对C++文件文本属性规则不等于已转换
git addgit add --renormalize .在受控变更中重新规范化跟踪文本先审查范围
git ls-filesgit ls-files --stage查看索引路径、模式与对象不是磁盘全部文件
git grepgit grep -n CardState HEAD -- src/在所选提交的源码搜索状态使用范围明确为HEAD
git grepgit grep --cached -n CardState核对候选中的规则不读取最新未暂存编辑

历史与内容溯源

命令用法场景与边界
git loggit log -5 --oneline检查最近五次修改意图显示为简略视图
git loggit log --all --graph --oneline观察多个入口的提交关系过滤会影响可见范围
git loggit log --grep=payment按提交说明调查消费任务说明匹配不是代码搜索
git loggit log -p -- src/card_service.cpp沿核心路径读取补丁路径历史需看上下文
git loggit log -S dailyLimit -p调查字符串次数变化区别于-G
git loggit log -G 'CardState.*Active' -p按补丁行正则查校验改动正则需正确引用
git showgit show HEAD:src/main.cpp读取某提交中的文件不改工作区
git showgit show :src/main.cpp读取索引候选文件路径须在索引中
git blamegit blame -L 20,45 -- src/main.cpp追查当前行相关提交继续调查背景
git notesgit notes add -m "reviewed in class" HEAD附加不改提交正文的说明notes引用另行共享

范围与对象名称

命令用法场景与边界
git loggit log main..feature/qt-console查主题独有可达提交两点为集合差
git diffgit diff main..feature/qt-console比较两端快照不同于log集合
git loggit log --left-right main...origin/main辨认双方独有提交基于本地已知信息
git diffgit diff main...feature/qt-console从合并基检查主题变化不等于log三点
git rev-parsegit rev-parse HEAD~2沿第一父连续两次定位父链不足会失败
git rev-parsegit rev-parse HEAD^2读取第二父位置需要相应父项

分支与HEAD

命令用法场景与边界
git branchgit branch --show-current确认当前分支名分离状态可能为空
git branchgit branch feature/export从当前入口建立名字不自动切换
git switchgit switch feature/export切换已有主题覆盖保护另行检查
git switchgit switch -c fix/name-check建立并切换修复主题先确认起点
git switchgit switch --detach campus-v0.1.1观察发布而不移动已有分支新工作需另建入口
git branchgit branch -m old-name new-name修正本地分支名称不自动改服务器名
git branchgit branch --merged main按祖先关系查询已包含入口不等于树相同
git branchgit branch -d feature/export按安全删除规则清理主题先核对所需工作
git symbolic-refgit symbolic-ref --short HEAD检查HEAD是否符号指向分支分离状态会失败

合并与冲突

命令用法场景与边界
git mergegit merge feature/export将来源整合到当前分支先确定接收方向
git mergegit merge --ff-only origin/main只接受可快进更新分叉时拒绝
git mergegit merge --no-ff feature/export要求适用情境保留合并节点已包含不强制重放
git mergegit merge --no-ff --no-commit topic形成待审查的普通合并现场之后核对候选
git merge-basegit merge-base --all main topic查询全部最佳共同祖先结果可能不唯一
git ls-filesgit ls-files -u -- docs/demo-policy.md读取未合并索引阶段缺失阶段可正常
git showgit show :2:docs/demo-policy.md读取当前整合某侧内容角色依操作解释
git mergegit merge --abort尝试返回合并前现场先保全重要编辑
git mergegit merge --quit退出合并管理并保留现场不等于恢复起点
git rereregit config rerere.enabled true在练习仓库记录重复冲突解决复用后仍测试

远程交换与上游

命令用法场景与边界
git remotegit remote -v确认fetch和push地址名称不代表权限
git remotegit remote add upstream SOURCE登记原项目来源先核对SOURCE
git remotegit remote set-url origin TARGET修正个人副本地址不授予写入权限
git fetchgit fetch origin取得对象并更新相应观察记录不自动整合工作分支
git fetchgit fetch --prune origin按映射清理失效跟踪引用本地分支另行管理
git fetchgit fetch origin --tags显式请求标签注意已有同名规则
git pushgit push -u origin feature/export共享主题并设置上游服务器规则可拒绝
git pushgit push origin HEAD:refs/heads/review明确目标分支更新核对两侧名字
git pushgit push origin --delete feature/export删除确认不再需要的远程入口不删除全部本地副本
git pullgit pull --ff-only抓取后仅接受快进整合分叉需另作决定
git branchgit branch -u origin/main main建立本地上游关联不改变全部推送规则

恢复与现场保留

命令用法场景与边界
git restoregit restore --staged -- src/main.cpp取消该路径暂存并保留编辑默认来源常为HEAD
git restoregit restore --source=HEAD --worktree -- src/main.cpp把工作文件恢复到指定提交会覆盖目标编辑
git restoregit restore --source=TAG --staged --worktree -- PATH同步恢复两个目标层先替换TAG与PATH
git resetgit reset --soft HEAD~1移动入口并保留候选与工作文件整提交模式
git resetgit reset --mixed HEAD~1移动入口并重置索引工作编辑保留条件另查
git resetgit reset --hard TARGET检出目标并重置相应状态先保全重要现场
git revertgit revert BAD_COMMIT追加反向变化撤销已共享错误可能冲突
git revertgit revert -m 1 MERGE_COMMIT按选定主线解释合并反向变化先检查父次序
git stashgit stash push -u -m "desk work"临时保全受跟踪和未跟踪现场忽略文件另有范围
git stashgit stash apply stash@{0}尝试应用保存现场并保留记录可能冲突
git refloggit reflog show HEAD调查本地入口移动序号随操作变化

历史整理与补丁

命令用法场景与边界
git rebasegit rebase main将所选主题重放到主线核对共享边界
git rebasegit rebase -i HEAD~3交互整理所选提交审查顺序与依赖
git rebasegit rebase -i --autosquash HEAD~2组织fixup补充先确认范围
git rebasegit rebase --onto NEWBASE OLD topic明确新基线和排除边界补丁应用不保证自足
git rebasegit rebase --continue接受解决后继续重放先add并检查
git rebasegit rebase --abort尝试退出并回到起点与skip不同
git cherry-pickgit cherry-pick FIX_COMMIT把修复移植到维护分支重新核对依赖
git format-patchgit format-patch -1 HEAD导出带提交信息的补丁不是完整仓库备份
git applygit apply --check change.patch检查补丁能否应用不证明业务正确
git amgit am change.patch按邮件补丁信息创建提交与apply范围不同
git pushgit push --force-with-lease origin topic按团队约定共享整理结果预期入口仍有边界

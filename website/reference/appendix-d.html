APPENDIX D

术语中英对照

本附录统一全书常用术语的译名。释义用于检索，不替代正文中的操作条件。尤其要区分名称、对象、工作区状态与托管平台功能；它们可能出现在同一条操作流程中，却不属于同一层。表D.1列出核心概念。英文词在不同工具界面中可能有缩写或其他译法，阅读时应以所指的实体和关系为准。

表 D.1 Git 核心术语中英对照
中文英文释义与边界
仓库repository保存对象、引用及相关管理信息的版本管理实体；工作区与其他附加数据需分别考虑。
裸仓库bare repository不提供日常编辑工作区的仓库形式；常用于本地共享中心实验。
工作区working tree当前展开在文件系统中、可直接编辑的一组文件。
暂存区／索引staging area / index描述候选目录树的条目集合；还可保存冲突的多个阶段，并非文件上传队列。
提交commit关联根树、父项和元数据的对象；提交操作通常同时推进当前历史入口。
快照snapshot某次记录所描述的项目状态；逻辑完整状态与底层对象复用并不冲突。
对象objectGit 内容寻址数据库中的带类型数据；核心类型为 blob、tree、commit 和 tag。
文件内容对象blob保存文件内容；路径名通常由树对象记录。
树对象tree object保存名称、模式及相应对象引用，用于描述目录结构。
附注标签对象tag object关联目标对象及标签元数据，可带说明和签名；与轻量标签的直接引用不同。
对象标识object ID按仓库采用的哈希规则计算，用于定位和校验对象；缩写需在当前范围可区分。
引用ref由名称提供对象入口的机制；符号引用还可通过另一引用解析。
HEADHEAD表示当前工作位置；可经本地分支解析，也可直接定位提交，初始时还可能尚无提交。
分支branch日常开发中通常指 refs/heads 下可随提交推进的历史入口。
标签tag通常用于稳定命名某个版本的引用；附注标签还引入相应标签对象。
远程配置remote当前仓库为通信来源／目标保存的地址、别名及映射等配置。
远程跟踪引用remote-tracking ref本地保存的来源位置记录，例如 origin/main；不是服务器的实时查询结果。
上游upstream本地分支的跟踪关联；fork 语境也常用此词指原项目，须结合上下文区分。
引用映射refspec描述来源和目标引用对应关系的表达式，常用于抓取或推送。
克隆clone建立来源仓库的本地副本；对象和历史范围受选项、来源及过滤条件影响。
抓取fetch获取所需对象并按映射记录相应位置；常规抓取通常不整合当前分支。
拉取pull先抓取，再按选项与配置整合；可能快进、合并、变基或因条件不符而拒绝。
推送push发送所需对象并请求对方更新引用；是否接受受权限、历史关系及服务器策略约束。
快进fast-forward把入口移到原端点的后继提交；不为这次更新额外创建合并提交。
合并基merge base双方的最佳公共祖先；复杂图可能有多个互不为祖先的最佳候选。
三方合并three-way merge结合公共基线与双方内容判断修改并尝试整合的模型。
合并提交merge commit具有两个或更多父提交的提交；本书基础实验主要采用双亲情形。
第一父项first parent普通合并中为合并前当前端点；用于主线观察或解释相对主线的变化。
冲突conflict相关整合规则无法直接协调修改而需人工决定的状态；包括文本及路径增删等情形。
冲突标记conflict markers工作文件中呈现双方或基线片段的标记；并非所有冲突都会以此形式出现。
语义冲突semantic conflict组合后的需求、接口或行为不一致；文本自动合并通过也可能存在。
变基rebase选择并重放一组提交，形成基于新位置的历史；需评估共享依赖与内容变化。
拣选cherry-pick在当前端点应用指定提交所引入的改动；不是直接搬动原提交对象。
恢复路径restore按明确来源更新工作区或索引中的所选路径，通常不移动当前分支。
重置reset依具体形式调整历史入口或索引；整提交模式和路径模式的作用不同。
抵消提交revert在当前位置应用指定改动的抵消并通常追加提交；不删除原祖先连接。
修订最近提交amend创建最近提交的替代版本；普通情况下沿用被替代版本的父项。
暂存现场stash通过 Git 对象与相关入口保存选定的未提交状态；范围和索引恢复受选项及现场影响。
分离 HEADdetached HEADHEAD 不经普通本地分支而直接定位提交的合法状态。
引用日志reflog本地相应引用过去位置的记录；保留和可用范围受配置与维护影响。
内容寻址content-addressable按对象类型、长度和内容参与计算的标识定位数据的机制。
可达性reachability从某入口沿相应对象关系能够到达目标的性质。
垃圾回收garbage collection包含对象整理及按条件处理过期不可达数据等维护工作，不等于立即删除所有无分支对象。
松散对象loose object未打入包文件的一种对象存储形式。
包文件packfile聚合和压缩对象的存储形式，可使用增量表示。
增量压缩deltification存储层借助其他对象的差异表示压缩数据，不改变对象的逻辑内容。
索引条目index entry描述路径、模式、对象、阶段及相关状态的数据；不只对应普通文件 blob。
钩子hook在特定事件中执行的程序入口；客户端检查不能天然代替服务器约束。
浅克隆shallow clone以深度或边界限制提交历史范围的克隆；会影响可用祖先信息。
部分克隆partial clone按过滤条件省略部分对象并支持相应后续获取的模式。
稀疏检出sparse checkout控制工作区展开范围的机制，不等同于删除其余仓库历史。
子模块submodule用 gitlink 记录另一个仓库的指定提交，并结合配置重建依赖。
子树整合subtree将外部项目内容纳入当前目录树的依赖组织方式之一。
多工作树multiple worktrees共享仓库对象等信息，同时维护多个相对独立检出现场的机制。
底层命令／日常命令plumbing / porcelain对更基础的构造操作与面向日常任务的命令层次的比喻。
签名signing用配置的签名机制为提交或标签等对象生成可验证记录；身份可信度还依赖密钥信任。
语义化版本semantic versioning按主、次、修订号表达兼容性承诺的一种项目版本约定。
个人派生仓库fork托管平台维护的一种仓库派生与协作关系，不等同于本地 clone。
拉取请求pull request平台上围绕来源和目标分支开展评审与整合的协作入口。
持续集成continuous integration通过自动流程构建、检查或测试选定成果的工程实践。

# 第16章　GitHub平台与图形化工具

本章在Git模型之上解释GitHub的账户、页面、Issue、PR、Actions、发布与设置，并逐项对照Sourcetree、Fork、GitKraken、Tower、GitHub Desktop与TortoiseGit。

本章以平台人工实践为主，不把当前仓库里的只读查询拼接成需要自动执行的流水脚本。GitEasy当前可见性按实际项目为准；没有访问权限时使用随书资源或自己的练习仓库。

## 阅读路径

- 从Git仓库到协作平台
- 账户准备与身份验证
- 读懂GitEasy仓库首页
- 建立自己的课程仓库
- 用Issue把问题写成可验收任务
- 提出并评审拉取请求
- 理解Actions检查与运行证据
- 发布、文档与项目展示
- 仓库设置与规则治理
- 图形化客户端与共同的Git模型
- Sourcetree：从文件状态进入历史图
- Fork：围绕差异与历史整理工作
- GitKraken：结合提交图与团队任务
- Tower：形成稳定的桌面工作流程
- GitHub Desktop：完成第一次平台贡献
- TortoiseGit：从目录位置理解仓库操作
- 独立贡献与工具选择练习

## 实践

1. 核对自己的账户、提交身份与仓库访问权限。
2. 在自己的教学仓库登记一个真实问题并建立主题。
3. 推送后核对base/head，创建范围清楚的PR。
4. 记录实际检查和评审状态，不虚构批准。
5. 用所选客户端与Git查询交叉核对结果。

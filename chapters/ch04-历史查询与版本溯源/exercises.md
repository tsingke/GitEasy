# 第4章　习题

按教材编号组织。实践题提交自己的输入、操作、证据与解释；线上活动仅记录实际发生的步骤。

## 习题4.1
给“看看最近历史”补充可观察的目标，分别设计按说明、路径和内容的查询。

## 习题4.2
在主实验中解释 `-S` Thursday 与 `-G` 正则结果可能不同的原因，并逐项阅读补丁。

## 习题4.3
说明 log A..B 与 diff A..B 分别操作什么；再解释两个命令中的三点记号为何不能套用同一含义。

## 习题4.4
画出一个双亲提交，标记第一父和第二父，并分别求 HEAD~ 2 与 HEAD^ 2。

## 习题4.5
选择 blame 指向的一行，继续读取提交与上下文，列出已知事实和仍需补充的背景。

## 习题4.6
把主实验的判定改成一个故意永远失败的脚本，说明为何无法据此确认真实故障位置。实验应在独立副本中进行。

## 习题4.7
说明 bisect run 如何区分通过、失败、跳过与执行异常。依赖命令缺失时，应该怎样避免误判？

## 习题4.8
保存一次二分日志，结束搜索并确认回到原位置，再写出可复现结论。

## 习题4.9
解释为什么长期报告应保存完整标识，以及完整标识仍不能代替仓库和访问条件。

## 习题4.10
为主实验写一份五段式调查记录，必须将技术变化与业务原因分开。

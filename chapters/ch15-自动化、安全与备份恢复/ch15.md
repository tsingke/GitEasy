# 自动化、安全与备份恢复：辅导材料

## 自动化案例：检查应当绑定哪一份内容
### 同名文件可能存在三份状态
作者把错误标题暂存以后，又在工作区修正，但尚未重新暂存。若提交前检查只读工作文件，它可能通过，而下一次提交仍包含错误候选。这种缺陷不是正则表达式不够严格，而是检查输入选错了。

本地提交检查应明确读取索引还是工作区；CI 则应说明检出哪个提交以及是否包含合并候选。检查结果的价值取决于它与将要接收的内容之间的对应关系。不能只写“已测试”，而不说明测试对象。

### 失败应当可解释
自动化报告应指明文件、规则和修复方向。只返回非零状态能阻止继续，却不足以帮助初学者改正。另一方面，报告也不应输出令牌、私钥或完整环境变量。工程可诊断性来自有选择的证据，而非无差别打印。

## 实验拓展：从备份恢复并证明范围
本独立实验创建一个完整 bundle，并在备份以后保留一份未提交草稿。恢复时核对提交内容，同时证明草稿没有自动进入备份。


### 生成备份，并明确未提交内容的边界

```bash
mkdir backup15
cd backup15
git init -b main
git config user.name "Git Learner"
git config user.email "learner@example.invalid"
printf '# Backup exercise\n' > README.md
git add README.md
git commit -m "docs: establish the backup exercise"
printf 'Room: A101\n' > room.txt
git add room.txt
git commit -m "docs: record the room"
SAVED15=$(git rev-parse main)
printf 'Uncommitted planning notes\n' > draft.txt
git bundle create ../full15.bundle --all
git bundle verify ../full15.bundle
cp draft.txt ../draft15-preserved.txt
cd ..
git clone full15.bundle restored15-extra
```



### 在独立副本中核对历史与文件

```bash
test "$(git -C restored15-extra rev-parse main)" = "$SAVED15"
git -C restored15-extra fsck --full
grep -q 'Room: A101' restored15-extra/room.txt
test ! -e restored15-extra/draft.txt
test -f draft15-preserved.txt
test -z "$(git -C restored15-extra status --porcelain)"
```


恢复成功的结论应限定为：bundle 中的相关对象和引用能够在新目录中重建，所核对的提交与文件一致。它没有包含未提交草稿、平台评审数据或其他外部资源。草稿之所以仍在，是因为实验另行复制，而不是因为 Git 备份自动覆盖了整个现场。

## 事件处置中的顺序与责任
### 凭据泄露先处理访问能力
有效凭据一旦进入可能被传播的位置，应优先撤销或轮换，核对实际访问与使用范围。只删除当前文件或改写历史，不能使已取得的凭据自动失效。历史清理服务于减少继续暴露与传播，不能替代权限处置。

处置报告应区分确认事实与待调查范围。不要为了复现泄露而把真实凭据复制到实验或日志中；教学应使用无效占位内容。涉及外部服务时，还要依据服务方机制检查会话、授权和相关自动化。

### 恢复演练要有验收目标
“备份文件存在”与“能够恢复业务”之间还隔着完整性、依赖、权限和时间成本。演练应从空目录或独立环境开始，按固定步骤重建，再验证关键任务。记录实际耗时和缺失材料，才有依据改进策略。

恢复目标可以分为需要保留到哪个时间点，以及允许多长时间恢复可用。两项目标影响备份频率、介质和演练方式。教学项目也应以具体任务表达，例如“恢复最近一次已发布课程资料，并能重新运行检查”，而非笼统要求“绝不丢失”。

## 迁移练习：为课程仓库制定交接清单
请列出代码与资料、外部数据、依赖、密钥配置、平台设置和未提交草稿分别如何交接。参考分析应说明每项内容的保存位置、访问条件、验证方式和负责角色。密钥不应以普通项目附件方式转交；可以重新授权时，应优先采用可追踪的授权流程。

清单的价值在于揭示仓库之外的依赖。若某项资料只能在原作者个人目录中找到，说明交付尚有缺口；若恢复只能由原作者口头指导完成，说明步骤还不足以独立复现。

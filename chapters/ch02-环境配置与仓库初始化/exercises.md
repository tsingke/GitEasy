# 第2章　习题

按教材编号组织。实践题提交自己的输入、操作、证据与解释；线上活动仅记录实际发生的步骤。

## 习题2.1
在一个全新目录中完成两次提交。第一次只写标题，第二次增加计划。提交最近两条历史和最终 status 的结果，并说明为何不要求哈希与教材相同。

## 习题2.2
同学已经配置了 GitHub 登录，提交时仍提示作者身份未知。这两种配置有什么不同？应查询哪两项设置？

## 习题2.3
新建文件后直接运行 commit，提示没有待提交内容。列出至少三种应检查的事实，并按检查成本排列顺序。

## 习题2.4
在 add 后、commit 前查看 log，新增的版本为什么还不存在？应使用什么命令检查本次候选变化？

## 习题2.5
把一个临时文件加入忽略规则，验证文件仍在磁盘上、不会出现在普通 status 中。写出证据，不要只给规则文本。

## 习题2.6
完成本地 clone，比较两个仓库的历史与文件。说明为什么原仓库的临时文件没有出现在新目录中。

## 习题2.7
你准备在线提交课程作业。哪些身份信息会进入提交历史？为什么示例邮箱不应原样用于需要关联个人贡献的正式仓库？

## 习题2.8
解释“工作区干净”为什么不能推出“目录中所有文件都已备份”。至少给出一个本章实际观察到的反例。

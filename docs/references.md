# 参考资料与原创说明

- [Pro Git，第二版](https://git-scm.com/book/en/v2)：知识组织与内部机制参考。
- [Version Control with Git，第二版](https://www.oreilly.com/library/view/version-control-with/9781449345037/)：对象、引用、索引与协作问题的结构参考。
- [高见龙《為你自己學 Git》公开教材](https://gitbook.tw/)及[第二版前言](https://cdn.kaochenlong.com/gitbook-v2-intro)：问题导向教学的参考。公开页面为最初选读来源，本轮另选读作者提供的本地图书。
- [Git官方手册](https://git-scm.com/docs)：命令行为与边界核对依据。
- [GitHub官方文档](https://docs.github.com/)：平台协作与自动化参考。

本项目的课程资料案例、辅导说明和知识结构图由作者教材项目原创编写。参考书的章节组织不直接移植，受限章节、截图与独特比喻不作为本项目内容转载。平台界面与命令行为会演进，学习时应结合本机版本和官方文档核对。

教材将数据模型、可复现实验与连续校园工程贯通，技术行为对照官方文档及执行记录核验；完整书目与选读范围保存在教材参考文献和editorial目录。配套项目不分发参考图书PDF。

## 本轮图解与封面来源

正文精选30幅内置图像生成工具制作的原创图解，提示词及修订记录见[提示词集](../assets/illustrations/prompts.json)；关系精度要求较高的机制使用独立矢量绘制。封面在作者蓝色流线模板基础上加入抽象分流、汇合意象，中英文黑体标题与作者署名独立排版，底部校名已删除；封底以三项教学特色作简洁说明。Git标志由Jason Long设计，采用[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)许可，来自[Git官方标志页面](https://git-scm.com/community/logos)。教材尚未出版，仅供学习交流，不得商用，文字、原创图表及版式的著作权归作者所有；范围见[教材使用说明](../BOOK-USE.md)。

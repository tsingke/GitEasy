# 参考资料与原创说明

- [Pro Git，第二版](https://git-scm.com/book/en/v2)：知识组织与内部机制参考。
- [Version Control with Git，第二版](https://www.oreilly.com/library/view/version-control-with/9781449345037/)：对象、引用、索引与协作问题的结构参考。
- [高见龙《為你自己學 Git》公开教材](https://gitbook.tw/)及[第二版前言](https://cdn.kaochenlong.com/gitbook-v2-intro)：问题导向教学的参考。仅研读公开内容。
- [Git官方手册](https://git-scm.com/docs)：命令行为与边界核对依据。
- [GitHub官方文档](https://docs.github.com/)：平台协作与自动化参考。

本项目的课程资料案例、辅导说明和知识结构图由作者教材项目原创编写。参考书的章节组织不直接移植，受限章节、截图与独特比喻不作为本项目内容转载。平台界面与命令行为会演进，学习时应结合本机版本和官方文档核对。
